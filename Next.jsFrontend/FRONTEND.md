# Event Ticketing – Next.js Frontend

This UI provides:
- Event CRUD
- Ticket type management with capacity validation
- Ticket generation (attendees or blanks)
- PDF download and email send triggers
- CSV import UI (optional)
- Check-in scanner and real-time reporting (polling)

Configuration:
- Set NEXT_PUBLIC_API_BASE_URL to your backend URL (see .env.example).
- PDFs are generated by backend; frontend triggers downloads.

Accessibility:
- Keyboard focus outlines enabled.
- Forms labeled with proper aria attributes.
- Scanner input supports pasting from USB scanners.

Real-time:
- Reporting uses SWR polling (2s). Replace with WebSocket/SSE if available.
